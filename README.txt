How to use:
1. Upload these files to Vercel as a static site.
2. Open the deployed URL.
3. Personalize a guest by adding:
   ?guest=Guest%20%26%20Family

Example:
https://YOUR-SITE.vercel.app/?guest=Nizam%20%26%20Family
